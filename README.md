# signal-vector

A Python-based framework for signal vectorization and representation learning. This project provides a full pipeline — from raw data parsing to model training and inference — for learning compact vector embeddings from signal data.

## Project Structure

```
signal-vector/
├── base/             # Base classes and abstract interfaces
├── data_loader/      # Dataset loading and batching utilities
├── data_parser/      # Raw data parsing and preprocessing
├── gen_pair/         # Pair generation for contrastive or metric learning
├── inf_tests/        # Inference and evaluation test scripts
├── model/            # Model definitions and architectures
├── show/             # Visualization utilities
├── test/             # Unit tests
├── utils/            # General utility functions
├── vec/              # Vector extraction and embedding logic
├── video_parser/     # Video/signal segment parsing
├── AMTC.py           # AMTC module implementation
├── config.json       # Configuration file for training parameters
├── save.py           # Checkpoint saving utilities
├── show_plot.py      # Plotting and result visualization
├── train.py          # Main training entry point
├── train_all.py      # Batch training across multiple configs
├── train_all1.py     # Alternative batch training script
└── requirements.txt  # Python dependencies
```

## Requirements

Install dependencies with:

```bash
pip install -r requirements.txt
```

The project is built primarily in Python (97.7%) with some Shell scripts.

## Configuration

Training behavior is controlled via `config.json`. Edit this file to set parameters such as data paths, model hyperparameters, batch size, and training epochs before running.

## Usage

### Single Training Run

```bash
python train.py
```

### Batch Training

```bash
python train_all.py
```

or

```bash
python train_all1.py
```

### Visualization

```bash
python show_plot.py
```

## Pipeline Overview

1. **Data Parsing** — Raw signal or video data is parsed via `data_parser/` and `video_parser/`.
2. **Data Loading** — Preprocessed data is fed into the training loop through `data_loader/`.
3. **Pair Generation** — Training pairs (e.g., positive/negative pairs) are generated by `gen_pair/` for metric learning.
4. **Model Training** — The model defined in `model/` is trained using `train.py`.
5. **Vector Extraction** — Embeddings are extracted via the `vec/` module.
6. **Evaluation** — Inference tests are run from `inf_tests/`.
